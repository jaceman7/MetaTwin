# MetaTwin 설계안

SF 관제실 스타일의 스마트 팩토리 디지털 트윈. 플레이 가능한 데모이며 5~10분 분량이다.
상태: M1~M4 구현 완료.

## 한 문장 소개

가상 배터리 셀 공장의 실시간 텔레메트리를 3D 트윈에 동기화하고, 고장을 진단하고, 조치안을 빠르게 시뮬레이션해 비교한다.

## 무엇을 증명하는가

| 역량 | 데모에서 보이는 것 |
|---|---|
| 실시간 데이터 연동 | 외부 서버의 텔레메트리가 WebSocket으로 들어와 설비에 반영됨 |
| 데이터 모델링 | 설비·센서 정의를 씬과 분리하고 ID로 바인딩 |
| 통신 신뢰성 | 연결 끊김 표시, 재연결, 순서가 뒤바뀌거나 오래된 데이터 처리 |
| 시뮬레이션 | 고정 시간 간격, 시드 기반 재현 가능한 공정 모델 |
| 3D 시각화·UX | 상태 색상, 온도 히트맵, 설비 선택과 상세 패널 |
| 에디터 자동화 | 레이아웃 데이터로 MCP를 통해 씬 구성 |

## 구조

```
[Python 설비 에뮬레이터] --WebSocket JSON--> [TelemetrySubsystem] --> [FTwinRegistry]
        ^                                                              |
        |                                                       [설비 Actor / HUD]
        +------------------- 명령(정지, 속도, 고장 주입) <--------------+

[FTwinTimeline 스냅샷] --> [FTwinPlant] --> What-if 결과 비교
```

- `UTelemetrySubsystem`: 연결, 재연결, 파싱, 신선도(stale) 판정
- `FTwinRegistry`(순수 C++, Subsystem이 소유): 설비 ID별 최신 상태
- `FTwinPlant`: 순수 C++ 공정 모델. `Tools/emulator/plant.py`와 같은 수식이며 `plant_golden.json`으로 일치를 검사한다
- `TwinWhatIf`: 스냅샷에 조치안을 적용해 180초를 예측하고, 고장 정지가 가장 적은 것 중 생산량이 가장 많은 안을 추천한다
- `FTwinTimeline`: 최근 10분 기록과 재생
- `ATwinMachineActor`: 상태를 표현만 함
- `TwinLine`, `FTwinAlarmLog`: 라인 요약과 알람 판정(순수 C++)
- `ATwinPlayerController`: 관제·드론 시점, 설비 선택
- `UTwinHudWidget`: 공정 개요, 알람, 추세 고장 주입, What-if, 재생

## 플레이 흐름

1. 관제 시점으로 공장 전체의 가동률과 알람을 본다.
2. 1인칭 드론으로 설비에 접근해 센서 값을 확인한다.
3. 고장을 주입한다(예: 냉각 펌프 열화). 온도 상승이 다음 공정의 병목으로 이어진다.
4. 조치안(감속, 우회, 정비)을 시뮬레이션해 처리량을 비교한다.
5. 조치안을 적용하고 회복을 확인한다.
6. 타임라인을 되감아 사고를 재생한다.

시작 후 6초 안에 서버에 연결하지 못하면 내장 시뮬레이션(`FTwinPlant`)으로 전환해, 에뮬레이터 없이도 전체 흐름을 진행할 수 있다. 연결됐다가 끊긴 경우에는 장애를 가리지 않도록 전환하지 않는다.

## 마일스톤

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| M1 (완료) | 데이터 경로: 에뮬레이터, Subsystem, 설비 3대 | 값 변화와 재연결이 화면에 보이고 테스트 통과 |
| M2 (완료) | 공장 레벨, SF 머티리얼·라이팅, HUD | 전체 라인을 탐색하고 설비를 선택할 수 있음 |
| M3 (완료) | 고장 주입, What-if, 타임라인 재생 | 플레이 흐름 1~6을 끝까지 진행 가능 |
| M4 (완료) | 최적화, 패키징, 소개 영상·README | RTX 4070 Laptop 1080p에서 60fps 목표, 빌드 실행 확인 |

## 모델의 한계

- 공정·열·마모 계수는 실제 설비에서 얻은 값이 아니다.
- 예측은 에뮬레이터와 같은 모델을 쓰므로 잘 맞는다. 실제 설비에 대한 정확도를 뜻하지 않는다.
- 진행 중인 열화는 해당 고장의 최종값까지 나빠진다고 가정한다.
